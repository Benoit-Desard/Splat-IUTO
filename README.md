## 🎓 Contexte de développement

Ceci est un projet universitaire visant à évaluer nos acquis Python (dans le contexte des SAE - Situation d'apprentissage et d'évaluation) durant le premier semestre de ma première année de BUT informatique.
Il se base sur le jeu Nintendo Splatoon, qui consiste en une guerre chronomètrée de territoire, dont l'objectif est d'avoir le plus de surface peinte (rapportant des points suivant la taille et la durée ed contrôle de cette zone peinte) dans une arène de combat.  
Ce projet nous mettais en concurrence, par groupe de développement de 4 personnes, car le but attractif de celui-ci étais de faire affronter nos algorythmes par groupe de 4 IA, les unes contre les autres en FFA (Chacun pour soi).  
Nous avons donc eu 1 semaine complète pour développer ce projet, durant lequel nous avons pût tester le comportement de notre IA dans une arène donnée contre d'autre algorythme d'IA, aussi en développement. 
en fin de projet, les professeurs universitaires ont donc récuperer le code IA de chacun des groupes, dans le but de les faires affronter dans un tournoi.
